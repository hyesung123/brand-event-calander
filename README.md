# moa 공개 캘린더

공개 방문자는 확정 행사와 추적 브랜드만 볼 수 있는 읽기 전용 캘린더입니다. 행사 데이터는 비공개 moa 사이트에서 읽고, Vercel Function이 비밀 토큰을 보관해 공개 페이지로 전달합니다.

## 배포 연결

1. 이 폴더를 전용 GitHub 저장소에 올립니다.
2. Vercel에서 해당 저장소를 가져와 프로젝트를 만듭니다. Framework Preset은 Other, Root Directory는 저장소 루트로 둡니다.
3. Vercel 프로젝트의 Production 환경 변수에 `MOA_SITES_BYPASS_TOKEN`을 등록합니다. 토큰 값은 브라우저 코드나 GitHub에 넣지 않습니다.
4. 기본 브랜치에 변경을 올리면 Vercel이 자동 배포합니다.

배포 후 `/api/public-feed`가 moa의 공개 피드를 읽습니다. 화면은 5분마다 새 데이터를 가져오며, 피드 API 응답은 짧게 캐시됩니다. moa의 추적 브랜드/확정 행사 데이터가 바뀌면 다음 조회 때 공개 페이지에도 반영됩니다.

## 개인 정보 범위

공개 피드에는 추적 브랜드 이름과 계정명, 확정된 행사 정보 및 원문 링크만 포함합니다. 검토 대기 행사, 실행 이력, 캡처 이미지, 메모와 로그인 정보는 공개 피드에 넣지 않습니다.

## 로컬 실행

정적 화면은 `dist/index.html`입니다. `/api/public-feed`는 Vercel 배포 환경에서만 동작하며, 로컬에서 확인하려면 같은 응답 형식의 개발용 API가 필요합니다.
